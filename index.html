    작업 순서와 연결 방법

    1. 연결 — 권장은 서버 모드입니다. 사주 무빙툰 관리자 페이지와 같은 사이트에 이 파일을 올리고(예: /admin/studio/), 관리자 비밀번호로 로그인합니다. 키는 서버 환경변수에만 두고, 생성된 이미지·영상·음성은 R2에 저장됩니다. 클링 결과 링크 만료나 CORS 문제도 서버가 영상을 바로 R2로 옮겨서 생기지 않습니다. 직접 모드는 혼자 테스트할 때만 쓰세요(npx serve 등 localhost에서 여세요).
    2. 화풍 고정과 캐릭터를 먼저 만듭니다. 캐릭터마다 ‘시트 생성’으로 정면·측면·표정 시트를 만들거나 직접 그린 시트를 올리세요. 첫 번째 이미지가 대표 레퍼런스입니다(금색 테두리).
    3. 컷마다 장면을 쓰고 등장 캐릭터를 고른 뒤 생성합니다. 선택한 캐릭터의 레퍼런스(캐릭터당 최대 2장)와 화풍 레퍼런스가 자동으로 첨부됩니다.
    4. 후보정에서 AI 수정·색 보정·9:16 크롭을 합니다. 클링에는 이 화면 그대로 전송됩니다.
    5. 말풍선에서 대사·나레이션을 넣고 등장 시각과 효과를 정합니다. 글자는 그림에 박히지 않고 영상 위에 합성됩니다. ‘🔊 음성 만들기’로 관리자 페이지와 같은 목소리 엔진(OpenAI·일레븐랩스)의 대사 음성을 붙이면, 음성 길이에 맞춰 컷이 자동으로 늘어나고 배경음악은 대사 동안 줄어듭니다.
    6. 영상화에서 클링으로 클립을 만들고, 영상 내보내기로 MP4(지원 브라우저) 또는 WebM을 받습니다. 내보내기는 실제 길이만큼 실시간으로 녹화되니 그동안 탭을 열어 두세요.

    직접 모드용: 클링 CORS 프록시 (Cloudflare Worker 예시)

    배포한 뒤 설정에서 API 주소를 https://내워커.workers.dev, 영상 파일 프록시를 https://내워커.workers.dev/fetch?url=로 넣으세요. 결과 영상 링크는 일정 시간 뒤 만료되므로, 완성되면 스튜디오가 바로 파일을 내려받아 브라우저 안에 보관합니다.
